# Kids-Learn: Grade 2–3 curriculum, level and media quality audit
**Snapshot:** main at `7ba297e805928d66c318723c6a5eee6a8133d58f`, November 5, 2026. **Status: planning baseline; no app fix is asserted in this document.**

## Scope and verification limits
Inspected the GitHub default-branch tree, grade configuration, grade-round generation and progress code, JSON curriculum inventory, Whack-a-Mole implementation and styling, currency generator, country curriculum, landmark photo manifest and existing audits. Compared priority skills with Michigan Department of Education math, ELA and social studies standards, Michigan K–12 science/NGSS and Ontario Mathematics (2020) / Language (2023). The fixed-bank structure was sampled for valid answer choices; this **was not** a full human line-by-line fact check, a complete automated browser run, a device visual audit, or a licensing clearance.

## Confirmed technical findings
1. **Grade/level mismatch (P0):** `data/content.json:GRADES` defines per-grade allowed ranges. Grade 2 and 3 exclude `trace` in normal configuration. However `app.js` advances `state.levels[id]` beyond `levelCap(id)` after enough good rounds (the “Super! Trying a harder level” branch). During question generation a later `gradeRange` clamp can serve a lower level than the tile displays. `showAll` / test mode bypass grade visibility and eligibility by design; review mode must be clearly labeled, parent-gated and distinguished from the normal grade catalogue. Check additional paths, including mixed rounds, old profiles, optional games and saved levels, on actual devices before asserting an exact reproduction for reported tracing.
2. **Curriculum breadth != depth:** Existing grade overview reports 28 Grade 2 sections and 27 Grade 3 sections including thinking/brain games. Many reuse short multiple-choice / fact recall. Topic names and numerical bank sizes do not establish skill competency.
3. **Authored bank inventory (snapshot):** `data/science.json` 111 fixed science facts + `data/grade23-extension.json` 40; `data/content.json` 127 GK + extension 20; reading `data/stories.json` 73 passages + `data/upper-grade-stories.json` 27 + extension 15 = **115 passages** with **293 associated multiple-choice prompts**. Thinking bank: 49 odd-one-out + extension 20, 84 sequences + extension 20. Numbers are file counts, not independent student skill coverage or guaranteed non-repetition. Latest PR #30 added 115 authored extension rows; this is valuable progress but not a complete curriculum.
4. **Currency media is inaccurate as a visual-identification tool:** 69 `assets/currencies/*.svg` files exist, generated by `scripts/generate-currency-assets.js`, which explicitly calls them educational illustrations rather than photographic currency; coin art is essentially a generic shape plus denomination text, and note art is a generic framed design. `country.js` uses these in recognition questions, so kids can answer by reading the denomination without learning to recognize the real note/coin.
5. **Landmark media:** 39 `assets/landmarks/*.svg` illustrations; `data/landmark-photos.json` has `ids: []`: **zero reviewed landmark photographs**. Cartoon drawings must not be used as photographic recognition tests. Retain maps and informational prompts until rights-cleared images exist.
6. **Mole Meadow / Whack-a-Mole:** 9 CSS-gradient holes, a flat grid and 5 SVG asset filenames (`mole`, `hedgehog`, `mouse`, `flower`, `meadow`); spawn weights in `game-themes.json` repeat `mole` three times. Current motion uses bottom-position transition and basic bounce/shake; the user-reported low-quality appearance is consistent with this limited art system. Needs a unified illustrated board, multiple poses, reactions, depth, screen-size reviews and non-punitive learning modes.
7. **Other media:** 16 topic photos, 85 ordinary illustrations, one standalone child-body picture and ~4,778 `audio/` files (including manifest). These counts **do not certify visual quality, permission to use, or full prompt narration**. Mixed emoji/flat SVG/photos creates style discontinuity.
8. **Content architecture:** Most static material has moved to external JSON files; generator logic appropriately stays in JS. Media files live outside JS. The next step is stable metadata per item: id, country/locale, grade, skill, standard, difficulty, interaction, correct answer(s), rationale, media IDs, alt text, rights/source and narration.

## Grade 2 / Grade 3 crosswalk — what must be taught, not merely quizzed
| Area | Grade 2 (Michigan baseline) | Grade 3 (Michigan baseline) | Needed app experiences |
|---|---|---|---|
| Reading / writing | Decode increasingly complex words; fluency; recount, compare, main point and key details; write organized paragraphs | Main idea + supporting details, inference with explicit evidence, explain relationships, written explanations and short research | Highlight evidence, assemble sentence/paragraph, infer and justify, edit writing, compare short passages |
| Number / operations | Place value to 1,000; addition/subtraction within 100 fluently and with models within 1,000; equal groups as multiplication preparation | Multiplication/division within 100, multi-step word problems, rounding, patterns, fluent addition/subtraction to 1,000 | Base-ten blocks, regrouping, number lines, arrays, fact families, worked reasoning |
| Fractions / geometry | Equal halves/thirds/fourths, partition shapes, shape attributes | Fractions as numbers on number lines; comparison; tiled area, perimeter, quadrilaterals | Fraction strips, partition-and-label, number-line drag, tile areas, build shapes |
| Measurement / data / money | Rulers, unit length, time to 5 minutes, U.S. coins, bar/picture graphs | Length, mass, liquid volume, elapsed time, scaled graphs, area/perimeter | Interactive rulers and clocks, real US/Canada coins depending on locale, scaled chart construction |
| Science | Matter/properties, organisms/habitats, landforms and water, fair comparisons | Forces/magnets, weather patterns, life cycles, traits and ecosystem change | Predict–test–observe–explain missions, graph weather, classify evidence, controlled investigations |
| Social studies / geography | Community history and change; maps, keys, directions, local economy/civic life | Michigan geography/history, human–environment interaction, local/state institutions and sources | Build/read local maps, compare past/present photos, source-based community investigations |
| Ontario-specific overlay | Financial literacy, data sorting, patterns/coding, community traditions and connections | Grade 3 coding with repeats, financial decisions, early communities and Ontario living/working | Localized Canada dollars/cents, sequences/loops, two-attribute data, contextualized Ontario history |

## Phased execution plan: one small independently testable PR per phase
**Phase 0 — Audit + release baseline (this document).** Freeze grade/skill taxonomy and asset quality bar, inventory existing content and media, create explicit issue checklist. No production behavior changes. Acceptance: documented verified facts vs unverified assertions; versioned prioritization; known failing tests and untested device requirements separated.

**Phase 1 — Correct grade/section/level (P0).** Refactor effective level as one function reused by home tile, generator, mastery, practice dashboard and completion feedback. Normal Grade 2–3 should not auto-show tracing/CVC/Clap It. Offer opt-in **Review earlier skills** explicitly labeled and protected by parent controls; preserve a child's prior achievements. Remove silent auto-progression beyond the configured grade max; do not manufacture endless levels. Acceptance: test every grade × section × beginning/middle/max × persisted level; no wrong-grade prompt or misleading level badge in normal mode; grade changes do not corrupt progress; older profiles migrated safely. Require UI test at 320, 390, 768, 1024 px and child profile / Show All / QA distinction.

**Phase 2 — Visual asset quality pilot (P0/P1).** First fully replace one currency learning sequence for US + Canada + India with recognizable, rights-cleared **front-face** coin/note pictures; each image has exact country/denomination/currentness/source/license/alt text. Start with a reviewed set of 10 landmarks (actual photos). Refresh Mole Meadow as layered illustrated meadow/soil/holes, consistent creature poses, feedback particles, animations, reduced-motion fallback and accessible hit targets. Acceptance: verified likeness, rights approval for app's commercial/educational use, visual review on real iPad, zero placeholder currency used in recognition tasks, offline resolution and color contrast. Then expand the art style consistently, not through bulk generic generated assets.

**Phase 3 — Grade 2 Explorer lessons (P1).** Cluster activities under Reading & Writing; Math; Science Lab; Community & Maps; Logic & Coding. Priority units: base-ten/regrouping, money/shop/change, rulers/clock/graphs, evidence-based reading and paragraph assembly, materials/plants/habitats, maps and community timelines. For each priority skill target >=12 curated scenarios and >=3 genuinely distinct interaction modes (build/drag/graph/read/explain), not just shuffled answers; maintain skill-level data manifests. Acceptance: Michigan grade 2 coverage matrix with evidence of an actual playable task for every required objective; editorial accuracy reviewed, answer keys verifiable, repeated-card rate measured.

**Phase 4 — Grade 3 Investigator lessons (P1).** Add multiplication and division models, fraction/number-line lab, area/perimeter builder, elapsed time/mass/data, inference and evidence reading, paragraph/research work, forces/weather/life cycles, map and historical-source comparison. Design 10+ short multistep missions (read→predict→manipulate→explain→reflect) and meaningful choices that change results. Acceptance: all high-priority Grade 3 standards represented by playable tasks; no early-K filler in regular sessions; grade-appropriate challenge without excess reading burden; voice, hints and accommodations.

**Phase 5 — Scale media + quality gates (P1/P2).** Expand actual reviewed landmark photos to 39; currency locales to all 7 supported countries where permission permits; harmonize anatomy, games and visual question banks; produce missing narration. Acceptance: complete item-to-asset link audit, license ledger, offline manifest validation, child/device QA; no dead links, overflow or inaccessible controls. Production release only once CI and device tests pass.

## Quality contract for future content JSON
Each item: `id`, `gradeBand`, `skills[]`, `standards[]`, `difficulty`, `prerequisites[]`, `interactionType`, `prompt`, `answers`, `explanation`, `mediaIds[]`, `audioIds[]`, `locale`, `reviewStatus`. Asset records: `assetId`, `path`, `type`, `sourceUrl`, `license/permission`, `attribution`, `altText`, `verifiedLikeness`, `reviewer`. **No question text or media blobs embedded in JS.** Generated questions have deterministic parameters, seeds for repeatability and constrained grade/skill pools.

## Test and editorial gates
- JSON schema and direct media/link integrity; duplicate/ambiguous answers, unsupported locale, wrong grade, wrong audio, incorrect currency denominations; source and licensing status.
- 100 seeded/generated questions per grade × section × reachable level with answer-in-choices, math invariants and answer explanation; test randomized distractors for plausibility, not merely uniqueness.
- Standard-to-lesson and lesson-to-standard matrix; count authored tasks and distinct interaction types; track fresh-card exhaustion after 20/50/100 rounds.
- Actual iPad and phone screenshots for small/large text, landscape and portrait, VoiceOver, reduced motion, no overflow, color contrast, tap response, sound fallback, offline airplane mode.
- Educational review of all priority content; no assertion of curriculum certification from code tests.
- Media licensing: U.S. Mint circulating coin policies https://www.usmint.gov/news/image-library/circulating ; U.S. banknote reproduction https://www.bep.gov/currency/currency-image-use ; Bank of Canada commercial reproduction permission https://www.bankofcanada.ca/banknotes/using-bank-note-images/ ; Royal Canadian Mint coin permissions https://www.monnaie.ca/en/faq . Do not assume an official web image is free to package into a commercial app.

## Product decision
**Keep Grade 3 in the same app** for now. Add an Explorer/Investigator presentation and more independent learning missions for older grades. Reconsider a separate Grades 4–5 app only after validated usage and curriculum needs warrant a split.
