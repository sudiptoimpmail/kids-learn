# App mascot

`owl-teacher.svg` is Professor Hoot, Learn & Play's mascot (set in `app.config.json` → `mascot`).
The owl picture was supplied by the app owner; its white background was removed and the picture is embedded (WebP)
inside the SVG together with the animation (bob and sway, breathing, blinking eyelids, twinkling stars, floating A B C).
The animation stops when the device has Reduce Motion on.
