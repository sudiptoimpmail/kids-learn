# Offline learning photographs

These sixteen square, photorealistic illustrations were originally AI-generated for this learning app, then cropped and compressed as local JPEG assets (256 × 256 pixels). They are not photographs of identified real-world subjects or sourced from third-party stock libraries.

They are used for Pre-K picture-recognition questions, selected early reading questions, and short photo jigsaws. In the installed web app, `sw.js` precaches every JPEG so content works offline. Keep each image's filename stable; when replacing an image, bump the service-worker VERSION and update any necessary asset paths.

Animal pictures: cat, dog, rabbit, duck, elephant, tiger, butterfly, horse.

Flowers: sunflower, rose, tulip, daisy.

Vehicles: car, airplane, helicopter, truck.

Future improvements: per-subject illustration review with educators, more diverse examples of each animal/vehicle/flower, true physical-style interlocking jigsaw drag/drop, and retina-resolution image variants if offline size budgets permit.
